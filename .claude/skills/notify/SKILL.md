# 掲載通知文を作る

`/notify <記事の番号 | slug | URL> [短縮版] [URLなし版] [タイアップあり] [◯◯社は除外]`。作業ディレクトリは `vizlabo_media`。

役割は事例マニア（運営：Vizlabo）の編集アシスタント。送付先は導入企業ではなく提供元（ベンダー）。同じ提供元の事例が複数あれば1通にまとめ、導入企業名を列挙する。文面はテンプレート固定で、差し込むのは記事タイトル・記事URL・導入企業名だけ。テンプレート外の文言を足さない、営業色を強めない、記事にない事例・企業名・数字を入れない。

## 手順

1. `git pull --ff-only origin main`
2. 記事を特定する
   - 番号（`8`）→ 事例セレクション #008。`用語1`・`用語#001` → 事例でわかる技術用語 #001
   - URL → 末尾の slug をそのまま渡す（`/articles/<slug>` も `/terms/<slug>` も可）
3. 文面を出す
   ```bash
   node scripts/vendors/notify.mjs <番号|slug> [--short] [--no-url] [--tieup] [--exclude ドメイン,…] [--all]
   ```
   - 「短縮版」→ `--short`、「URLなし版」→ `--no-url`、「タイアップあり」→ `--tieup`、「◯◯社は除外」→ `--exclude <ドメイン>`
   - 既定では、この記事でまだ連絡していない提供元だけが出る（`data/vendor_contacts.json` の記録）。全社出すなら `--all`
   - 削除依頼を受けた提供元（`data/blocked_vendors.json`）は自動で除く
   - 紹介元（`data/intro_sources.json`。協議会・メディアなど提供元ではない掲載元）は自動で除き、「要確認」に出る。提供元と誤解されたと連絡を受けた掲載元は、削除せずここに足す
4. 出力をそのままユーザーに渡す（前置き・解説・要約は書かない）。各社のブロックは「### N. 提供元名 ／ 掲載事例 ／ 提供元（連絡済みか初めてか） ／ 連絡日・前回の連絡（連絡済みの先だけ） ／ 文面のコードブロック」、最後に「要確認:」が1行
   - 連絡済みの先には、これまでの記事ごとの連絡日（記録がなければ公開日からの推定）と前回からの日数が出る。60日以上空いていると「★再送の目安」が付く。省略した記事は連絡に数えない
   - 「要確認」に「会社名が未登録」が出たら、`data/vendor_contacts.json` のその提供元の `company` に正式名称を書いて再実行すると見出しに出る（次回以降も使われる）
   - 導入企業名が非公開の事例も文面を作る（企業名は入れず件数に含める）。「要確認」に出るので、その旨をユーザーに伝える（推測で企業名を入れない）
   - 「文面を作っていない」が出たら、その旨をユーザーに伝える
5. ユーザーが「送った」と言ったら記録する
   ```bash
   node scripts/vendors/contacts.mjs --notified <番号|slug> [YYYY-MM-DD]
   ```
   一部の提供元だけ送った場合は、送らなかった先をオプションで分ける。
   - 以前の記事で連絡済みのため省略した先 → `--skip ドメイン,…`（連絡済み扱い・連絡日は付けない）
   - サイト・フォーム停止などで送れなかった先 → `--hold ドメイン,… --memo "理由"`（未連絡のまま残し、memo に理由を書く）
   - 例: `node scripts/vendors/contacts.mjs --notified 36 2026-11-09 --skip armg.jp,hrbrain.jp --hold businesscoach.co.jp --memo "問い合わせフォーム停止中"`
   記録したら `data/vendor_contacts.json` と `content/articles/VENDORS.md` をコミットして push する。

## テンプレート（scripts/vendors/notify.mjs に固定。ここでは変えない）

- 事例が1件なら「導入事例（{導入企業}様）」、複数なら「導入事例{件数}件（{A}様、{B}様）」。敬称は「様」、企業名は記事の表記で法人格を付けない
- 導入企業名が非公開の事例は企業名を出さない。非公開だけなら「導入事例」「導入事例{件数}件」、企業名ありと混在なら「導入事例{件数}件（{A}様ほか）」
- 短縮版：記事紹介・転載なし・修正削除対応・署名は残し、追加掲載の案内と「SNSで使って大歓迎」の一文を削る（600字以内）
- URLなし版：記事URLの行を「記事URLはご返信いただければお送りします。」に置き換える
- タイアップあり：追加掲載の段落の末尾に「比較検討層に届く事例記事のタイアップ制作も承っております。」を足す
