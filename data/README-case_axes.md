# case_axes.json（事例3選の比較軸タグ）

`scripts/tag_axes.py` が `data/cases.json` の本文（課題文・要約・施策・定性成果）からキーワード規則で読み取った、
3選の比較軸7つ（出発点・導入範囲・作り方・期間・推進者・きっかけ・つまずいた壁）の値。
事例IDごとに `{軸: [値, …]}`。本文に該当する記述がなければ `[]`（推測で埋めない）。

- 既存項目で判定できる軸はここに持たない：規模＝`case_facets.json` の `size`、業種＝`customer.industry`、
  成果の種類＝`case_facets.json` の `effects`、解き方＝`productCategory`（粗い代理。実際の「手」は本文で読む）
- 値が2つ以上入っている事例は、軸の値として使わない（どちらとも言えない）
- 2026-10 時点の抽出精度の目安（抽出例を目視）：出発点・導入範囲・期間・きっかけ（人手不足／法改正／システム更新期限／コロナ）は
  おおむね使える。作り方は「伴走・コンサル」「内製」が使える。推進者・つまずいた壁・きっかけ（顧客要求／トラブル）は件数が少ないか
  誤検出が多く、記事に使う前に本文で確認が必要
- 再生成：`python3 scripts/tag_axes.py`（cases.json 更新のたびに回す）。抽出例の確認：`python3 scripts/tag_axes.py --sample 期間`
