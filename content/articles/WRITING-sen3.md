# 「選」記事（sen型・事例3選）の書き方

1つのテーマで掲載事例から3本を選び、**並列の「選」**として成果の数字とともに紹介する短い版。
テンプレートは10選と同じ `format: "sen"` を使う（`items[]` の件数は固定されていないので、3件入れれば目次・カルテ・成果チップは01〜03で自動的に組まれる）。

10選との違いは「量」ではなく「選び方」と「書き方」にある。10選は幅（業種・業務のばらつき）を見せる記事、3選は**1つの軸で並べた対比**を見せる記事。
10選の書き方は [WRITING-sen.md](WRITING-sen.md)。

## 0. この記事の性質と限界

- **順位を付けない。** 3本でも並列の「選」であり、ベスト3ではない。順番は対比が読みやすい並び（小→大、短→長など）の編集判断。
- **選定基準と範囲を冒頭で明示する**（`criteriaNote`）。母数（当サイト掲載◯件のうち該当◯件）、選定基準、順位でないこと、市場の代表性を示さないこと。本数が少ないぶん、**なぜこの3本か**が読者に伝わる書き方にする。
- 数字は各事例の `results` に記録された公開情報のみ。**タイトルに使う数字は必ず記事内の3本のもの**にする。
- 3本から一般化しすぎない。まとめには「この3本の範囲では」の断りを1文入れる。

## 1. 企画と選定

- 企画の起点は10選と同じく「そのテーマで素材級の事例が何件あるか」。3選は**候補6件以上**が目安（3件ぴったりでは選べない）。
- 候補の数え方の例（数値成果あり・課題文80字以上をタグ別に集計）：

```bash
python3 -c "
import json,collections;cs=json.load(open('data/cases.json'))
cnt=collections.Counter(t for c in cs if c.get('results') and len(c.get('challengeDetail') or '')>=80 for t in c.get('tags',[]))
print(cnt.most_common(30))"
```

- 母集団を機械的に抽出（タグ・キーワード・カテゴリ）してから、**全件の内容を読んで**選ぶ。
- **並べる軸を1つ決める。** 3本は少ないので、軸がないと「たまたま3本」に見える。軸の例：
  - 規模で並べる（従業員20名・300名・3,000名）
  - 減らしたもので並べる（時間・ミス・コスト）
  - 手の入れ方で並べる（入力を減らす・照合を減らす・運ぶ工程をなくす）
- 選定基準：数値成果が具体的／業務・業種が重ならない／**提供元（ベンダー）は3本とも別**にする（10選の「同一ベンダー3本まで」より厳しくする）。
- 落とした事例の理由をメモに残す。

## 2. 各項目の書き方

- `headline`：見出し規範に従う（情景か発見の断言。カギ括弧強調・ダッシュ補足・講義口調は使わない）。その事例の数字か固有の状況を入れる。3本の見出しを並べたとき、**軸の違いが見出しだけで分かる**ようにする。
- `body`：2〜3文。〈状況 → 何を読ませたか／変えたか → 何がどれだけ減ったか〉。10選より1本あたりの読みどころを厚くしてよいが、3文を超えるなら削る。事例データ（課題文・成果）の範囲で書き、盛らない。
- 会社名・業種・規模・成果チップ・事例リンクはテンプレートが自動で出す（bodyで重複させない）。
- 結び「〜1本。」は3本中**1件まで**。ダッシュ「——」は1記事に2回まで。本文の「」は固有名詞・製品名・原典からの引用だけ。

## 3. 構成とフィールド

扉（title・lead）→ criteriaNote（枠）→ サムネイル → 目次（3本の見出し）
→ 01〜03（headline＋カルテ＋body＋成果チップ＋事例リンク）
→ まとめ（outroTitle・outro）→ あわせて読む（relatedSlugs）→ 掲載サービス＋まとめて問い合わせ（自動）→ ポリシー表記

| フィールド | 3選での書き方 |
|---|---|
| `title` | 2行。1行目は情景か発見、2行目は「成果で見る導入事例3選」など本数を明示 |
| `lead` | 3社の業種・業務のばらつきと、並べる軸を一言で示し、問いで締める |
| `criteriaNote` | 母数・基準（軸を含む）・「順位ではない」・「市場の代表性を示さない」 |
| `items[]` | 3件。順番は軸に沿った並び |
| `outroTitle` / `outro` | 3本の対比から見えた共通項＋「この3本の範囲では」の断り＋読者の次の一歩（製品推薦にしない） |
| `relatedSlugs` | 同テーマの10選があれば必ず入れる（3選は入口、10選は深掘り） |

## 4. 公開前チェック

- criteriaNote に母数・基準・「順位ではない」があるか。軸が書かれているか。
- タイトルの数字が記事内の3本の実数か。
- 各 body の数字・事実が事例データと一致するか。見込み値に断りがあるか。
- 提供元が3本とも別か。
- 3本の見出しを並べて、軸の違いが読めるか。
- まとめに「この3本の範囲では」の断りがあり、製品推薦になっていないか。
- `.claude/skills/yomiyasu` のリンターを通したか（手順は README.md）。
