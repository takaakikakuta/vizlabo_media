# コラム下書き：事例に出てくる数字、いちばん多いのは「工数◯%削減」説

既存7型（分かれ道・現場・導入前・地図・越境・舞台裏・選）のどれにも当たらない、データ集計を主役にしたコラムの下書き。
まだサイトには載らない（`lib/articles.ts` は `content/articles/*.json` だけを読む）。

| ファイル | 役割 |
| --- | --- |
| `column.md` | 本文（見出し・表・引用・参照事例） |
| `analyze.py` | 本文の数字を `data/cases.json` から再計算するスクリプト |
| `numbers.json` | `analyze.py` の出力。本文の数字はここから取る |

公開するには、本文を載せる記事型（見出し＋段落＋表を持つコラム型）をテンプレートに追加する必要がある。
集計の分類は語による近似なので、本文で「分類は近似で境目に誤りがある」と断っている。断りは消さない。
